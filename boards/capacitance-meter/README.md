## 功能与边界

当前只包含测量核心，不包含完整充电、维持供电、主控制器或显示系统。测量精度 ≤3% 是设计目标，尚无实测结论。

J1 为 CAP+、J2 为 CAP−，两个直插座中心距 5 mm。使用 Mill-Max 0285-0-15-15-16-27-10-0；孔径与装配约束见[原始设计说明](docs/design-notes.txt)。R30 / R31 为 0 Ω 0805，分离板内 Force / Sense 走线，但这不构成四触点 Kelvin 夹具。
