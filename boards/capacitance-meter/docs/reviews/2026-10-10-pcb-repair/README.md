## 已完成的改动

补齐模拟设定与反馈、ADC 滤波、复位及使能、SPI、I²C、两路供电、地和校准接口。全部路径逐网确定，再通过原生 API 写入；每批新增路径用原生 DRC 定位并修正间距问题。

C22 旋转 180°，调整差分滤波连接；C23 移到 `(52.5, 30.5) mm`；J4 中心从 `(47, 40)` 移到 `(47, 40.5) mm`，为栅极关断和校准走线留出间距。更新相应位号，修正旋转后倒置、压过孔和靠近焊盘或板边的文字。

顶层和底层均建立并实际填充 AGND 参考面，禁止保留孤岛。用 67 个只限制覆铜的区域保护功率回流、取样和校准路径；这些区域不禁布线，也不改变 DRC 的铜间距规则。

## 回流与取样

主放电路径仍为 `J1 → Q1 → R10…R14 → 专用回流线 → J2`，保留 1.2 mm 功率走线及原有双过孔换层。

模拟地在 **R14.2** 单点汇接：从该焊盘另引一条 0.35 mm 短支路到 `(39.2, 34.5) mm` 的 AGND 过孔及参考面。J2 两面的地铜均隔离。这样恒流运放与 ADC 以分流电阻低端为参考，不把 R14 至 J2 的主回流走线压降叠加到恒流反馈中。

R14.2 至 `(40.48, 33) mm` 取样过孔为独立低端引出；之后分别到 R27.1 和 J4.4。J4.4 没有沿功率回流线取样，也没有直接并入普通地铜。R27.1、相关过孔和沿途铜线均有禁止覆铜区域。J2 至 R31.1 的电容负端取样同样保持独立。

J4 的使用约束：

| 引脚 | 信号与参考 |
| --- | --- |
| 1 / 2 | SENSE_POS / SENSE_NEG，电容端口电压 |
| 3 / 4 | SHUNT_HI / 分流低端独立引出，测量分流电压 |
| 5 / 6 | VCAP_HALF / AGND |
| 7 / 8 | VREF2V5 / AGND |
| 9 / 10 | DAC_VOUT / AGND |

J4.4 在逻辑网表中仍叫 AGND，但在 PCB 上是高阻测量支路。外部测试夹具不能把它当电源地使用，也不能用多通道仪器的共地引线把它与其他地端形成额外回流。J1/J2 仍只有两个实际触点，板内独立取样不能消除插孔接触电阻。

## 尚未验证与下一步

本次完成的是 PCB 布线、回流修正和原生规则检查，没有实物上电或样板测试。保持“设计中”状态，不升级为“已验证”。

1. 核定外部 +5V_A / +3V3、主控接口及上电/失电状态；验证 LOAD_EN 默认关断与复位释放。
2. 核定 Q1 的线性 SOA、散热和环境温度。按 3 V、0.5 A、0.5 Ω 分流电阻估算，Q1 起始耗散约 1.375 W；这是理想电路估算，不是温升或 SOA 通过结论。
3. 样板测量恒流回路启动、阶跃和低电压端的稳定性，确认 C5 补偿后再确定测量窗口。分别校准电压、电流和时基；≤3% 仍是目标。
4. 核对实际电容脚径、插入深度、45 mm 高本体的支撑、Q1 散热器及连接器插拔空间。J4 已移动 0.5 mm，机械资料须采用本次位置。
5. 整理原理图警告和采购属性，完成板厂及装配复核后再建立对应源提交的投板标签。
