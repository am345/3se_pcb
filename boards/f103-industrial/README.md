## 功能与接口

现有设计包含 SWD、UART、CAN、按键、LED 和蜂鸣器；详细连接以原理图为准。V1 已取消旧设计中的 BMI088、USB 和纽扣电池，VBAT 接 3.3 V。不能把其他目录中的旧 F103 板或 V2 当作本板。

固件相关约束见[历史审查](docs/reviews/2026-09-26/prefab-review.md)：12 MHz HSE、CAN 的 PB8/PB9 重映射、PA15 使用时释放 JTAG 并保留 SWD。该记录中的本机证据路径是历史来源，不是仓库内依赖。

## 打开与编辑

用嘉立创 EDA 专业版打开上述 `.eprj3` 入口，保留整个 `hardware/` 目录。原理图、PCB、规则及嵌入的符号 / 封装 / 器件库均已随工程保存。后续以此目录为维护入口，旧 `.eprj2` 仅保留在原位置作为迁移来源。

本次只转换存储格式。保留原来的内部 ID、器件、焊盘网络、走线、过孔、铺铜与设计规则；没有布线或电路修改。
