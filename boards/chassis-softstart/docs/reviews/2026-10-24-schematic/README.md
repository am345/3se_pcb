## 做法

1. 工程骨架用 [easyeda-eprj3](https://github.com/easyeda/easyeda-eprj3-skill/tree/40c94e129df18e94232f8c94260134bfcac6cabf)（`40c94e1`）的 `init.js` 生成，格式 companion 为 [easyeda-format-skill](https://github.com/easyeda/easyeda-format-skill/tree/9e42727cc4cf13a8e442140e8e7794ae94d5f41b)（`9e42727`），两者都克隆在仓库外的临时目录。骨架的 `validate.js` 为 0 错误、0 警告；`audit-format.js` 只报图框 COMPONENT 缺 `groupId`/`locked`，客户端重开后会重写该记录。
2. 用 `lceda-pro open --headless true` 打开工程，经编辑器 API 清空页面，再按逐点规划的坐标重画：
   - 器件按立创编号从系统库放置（`lib_Device.search` + `sch_PrimitiveComponent.create`），每个器件放置后读回引脚坐标，与规划逐脚比对。第一次比对发现 100 nF 电容的引脚间距与原用电容不同，调整位置后全部一致。
   - 导线每个网络一次创建、只带一个网络名；GND 用网络标识。没有调用客户端的 `autoRouting`、`autoLayout`。
   - 布局参照 TI LM5069 手册图 27。位号、型号和网络名的位置逐个调整，避开导线、连接点和其他文字；C2、C3 标注原为 6.75 号小字，改回默认字号。
   - 标题栏：版本 V0.1，绘制“AI 草稿”，板子改名为“底盘缓启动”（与超级电容组的写法一致）。
3. 导出 Protel 2.0 网表，用脚本与[设计说明](../../design.md)第 3 节的连接计划逐脚比对；运行原理图规则检查 `sch_Drc.check`（严格模式）。
4. 关闭会话后从磁盘重新打开工程，重复第 3 步，并读回标题栏字段。
5. 由重开后的会话导出 3200 px 原理图渲染图，分 6 块按原分辨率逐块检查。当天的图后来被覆盖，现存最接近的是 [V0.1 最后的渲染图](../../../images/schematic-v0.1-2026-10-31.png)。

## 同日换料与复核

- 按立创商城 2026-10-24 的自营库存，D3（C461543）、Q2（C3197152）已停售，C2/C3（C14663）只能订货，换为 C2128、C109310、C307348。
- 做法：读取旧件的坐标和引脚，删除后在原位置放新件，逐脚比对引脚坐标。Q2、D3 的引脚号和坐标与旧件一致；C307348 的符号默认朝向不同，按原角度放下后引脚变成横向，改为 0° 后与原导线一致。改角度时标注随器件转到了导线旁，已重新放回原位。
- 用户在可视窗口查看期间，窗口保存过一次：D1 的 GND 标识从 y = 630 移到 y = 635，连接不变，按原样保留。
- 关闭会话后从磁盘重开：26 个器件、13 条文字，规则检查 0 错误 0 警告，网表 14 个网络、62 个引脚与连接计划一致；渲染图已由重开后的会话重新导出。

## 客户端问题与处理

- 客户端 4.1.71 用 `sch_PrimitiveText.delete` 删除文字后，内存里已删，保存时却不写进文件，从磁盘重开后旧文字会回来（删除返回成功、保存返回成功，但文件没有删除记录；同一会话里删除矩形会正常写入）。超级电容组也记录过同样的问题。
- 处理：重画时删掉的 16 条旧文字（原功能块标题和设计说明），在关闭会话后按客户端自己的删除记录格式（同 ID、新票号、空记录体）用脚本原位写进文件，各 DOCHEAD 的票号同步为新的最大值；随后由客户端重开读回，确认只剩新建的 13 条文字。

## 未执行与例外

- 上述删除记录是用脚本直接写进文件的，不是客户端自己保存的；以客户端重开读回、规则检查、网表比对和重开后的渲染图为准。
- 重开后 6 个测试点显示为灰色（编辑会话中为深红色）。它们的“加入 BOM”为否，网表里有其引脚，规则检查没有告警；灰色是不是不进 BOM 器件的显示样式，没有在客户端界面里确认。
- `easyeda-eprj3` 的 `validate.js` 在客户端保存后的文件上抛出脚本异常（`Cannot read properties of undefined (reading 'docType')`），这一项不算结论。
- 检查时只看了导出的渲染图，没有在客户端可视窗口中逐项浏览。
- 没有 PCB、DRC、制造输出，也没有样板实测。
- 器件数据手册核对范围见[设计说明](../../design.md)第 5 节；标注“仅立创参数”的器件仍待读手册。
