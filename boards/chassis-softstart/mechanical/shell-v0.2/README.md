# 缓启动 V0.2 保护壳（底壳 + 上盖对扣）

给底盘缓启动 V0.2 焊线版（35.5 × 17 mm，四角焊 14AWG 线）做的打印保护壳，共两件，不用螺丝。

- **底壳**：平底，用 VHB 一类双面胶贴在底盘上。
- **上盖**：从上面扣下，外裙套住底壳的止口，两条长边的卡筋扣住。
- **焊线**：四根焊线从两端水平引出（左边 IN+、IN−，右边 OUT+、OUT−），夹在底壳和上盖的半圆缺口之间。上盖缺口比线小，扣上后压住线，导线拉力由外壳承受，不全压在焊点上。
- **全封闭**：底面测试点不开窗，测量时拆上盖、把板子取出来。两只指示灯上方的顶板从里面减薄到 0.4 mm，用浅色料打印可以透光。

## 尺寸

坐标同 PCB：原点在板子左下角，x 0～35.5，y 0～17，PCB 占 z 0～1.6，器件在顶面。

| 项目 | 数值（mm） |
| --- | --- |
| 外形 | 40.3 长 × 21.8 宽 × 10.1 高；竖棱圆角 R2，顶面外棱 R0.8，底面是平面 |
| 壁厚 | 四周 2.0，底 1.2，顶 1.2 |
| 内腔 | 四周比板子大 0.4；板底下留 1.5（焊线芯和底面焊锡）；板顶上留 4.6（最高的器件是 C4，1210 封装，最高约 2.7） |
| 分缝 | z 3.7，即焊线中心高度：线外径按 3.6，线底离板面 0.3 |

| 焊线缺口 | 两端各两个，中心 y 2.5、y 14.5，正对 J1–J4：底壳是 Ø3.6 下半圆；上盖是 Ø3.2 上半圆，扣上后把线压扁 0.2 |

## 装配

1. **焊线**：四根 14AWG 线从顶面插进 J1–J4，在底面焊好；线芯剪到底面只露约 1 mm。
2. **理线**：每根线贴着板面水平弯向外侧，IN 两根朝左，OUT 两根朝右。
3. **放进底壳**：板子放进底壳，两条长边落在托板台阶上，四根线落进两端的半圆缺口。
4. **扣上盖**：竖直往下压到“咔”一声、分缝贴平。
5. **贴到底盘**：底面贴双面胶，按到底盘上。
6. **拆**：用指甲插进分缝，把上盖往上撬。

## 打印

- **方向**：底壳开口朝上；上盖顶面朝下。两件都不用支撑。
- **参数**：层高 0.2 或 0.16、0.4 喷嘴、4 圈外壁。
- **用料**：实心体积底壳 2.45 cm³、上盖 1.36 cm³。PETG 约 5 g，没有实称。
- **先试配**：
  - 扣不进：把 `joint.gap` 改成 0.15～0.2，或者把 `bead.h` 改小；
  - 扣上松：把 `bead.h` 改大到 0.4；
  - 线压不住：把 `wire.clamp` 改大；
  - 量一下实际线径，把 `wire.od` 改成实测值。

## 温度：材料要选耐温的

- 仿真结果（不计焊线导热，见[电流与温升仿真](../../docs/reviews/2026-10-31-wire-v0.2/simulation.md)）：持续 10 A、在开放空气里时，板面约 72–75 °C。
- 装进封闭的壳里散热更差，板温还会更高，具体高多少没有算。
- **材料**：
  - PLA 约 60 °C 就软了，不能用；
  - PETG 的玻璃化温度约 80 °C，余量很小；
  - 建议用 ASA、ABS 或 PC，耐温都在 100 °C 左右或以上。
- **双面胶**：常见 VHB 长期耐温在 90 °C 左右，按所买型号核对。
- 如果实测壳里过热，可以在上盖开散热槽，或者改用不封闭的形式。

## 检查

`node shell.mjs <输出目录>` 会把板子、器件和焊线建成实体，和底壳、上盖分别求交集。

- **建模范围**：
  - Q1 按 Gerber 焊盘外沿量；
  - C4、R1、D1、D2、U1、Q2、D3 和 0603 阻容、指示灯，按位置和封装最大外形估成方块；
  - 焊线按 Ø3.6，从焊盘竖起到分缝高度，再水平伸出；
  - 底面焊点按 Ø3.2、高 1.0 估。
- **2026-11-07 的结果**：除了下面两处有意的过盈，没有干涉。
  - 上盖和焊线重叠 4.27 mm³：上盖缺口半径比线小 0.2，在 1 mm 厚的外裙里压住四根线；
  - 上盖和 PCB 重叠 0.2 mm³：两根压板筋各压 0.05。
- **底壳和上盖**：扣好后重叠 0 mm³。
- **生成工具**：replicad 1.2.1（OpenCascade 内核），先在本目录执行 `npm i replicad replicad-opencascadejs`，需要 Node。
- **没有做的**：
  - 器件外形是按封装估的，没有用 3D 模型核对；
  - 打印、试扣、卡筋松紧；
  - 14AWG 线实际外径，以及贴着板面急弯时能不能弯过来；
  - 壳内温升；
  - 双面胶的粘接强度。
