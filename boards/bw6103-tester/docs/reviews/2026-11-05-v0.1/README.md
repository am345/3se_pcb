## 需求依据

- 用户在 2026-11-04 确认了以下几点：
  - 用淘宝 SOT23 翻盖测试座，带 CNV-SOT23-5L-DIP 转接板；
  - 用 1 mV 步进的数字电源直接供电；
  - 一个工位；
  - 负载照电容组每串的接法，加 LED 脚红灯和跳线。
- 挑片窗口 2.93–2.98 V 和测试方法沿用[超级电容组设计说明](../../../../supercap-bank/docs/design.md)第 4 节。
- BW6103 规格书（2026-11-04 访问）用到以下内容：
  - 引脚：1 VDD、2 GND、3 SEL、4 LED、5 IOUT（第 2 页）。
  - 框图：IOUT 和 LED 脚都是接 VDD 的 P 沟道高边开关（第 2 页）。
  - 典型应用：IOUT 经电阻接地，LED 脚经电阻和 LED 接地，VDD 与 GND 之间接电容（第 1 页）。
  - 绝对最大额定值：VDD 6.0 V，IOUT 1000 mA，LED 脚 30 mA，功耗 350 mW（第 3 页）。
  - SEL 接低时，VDET 2.88 / 2.95 / 3.02 V，VWAR 2.98 / 3.05 / 3.12 V（第 3 页）。
  - 规格书没有给迟滞、温漂和响应时间。

## 绘制方法

1. 用 [easyeda-eprj3](https://github.com/easyeda/easyeda-eprj3-skill/tree/40c94e129df18e94232f8c94260134bfcac6cabf)（`40c94e1`）的 `init.js` 生成工程骨架，格式 companion 为 [easyeda-format-skill](https://github.com/easyeda/easyeda-format-skill/tree/9e42727cc4cf13a8e442140e8e7794ae94d5f41b)（`9e42727`）。两者都克隆在仓库外的临时目录；骨架的 `validate.js` 为 0 错误、0 警告。
2. 用 `lceda-pro open --headless true` 打开工程，经编辑器 API 绘制原理图：
   - 从系统库放置器件；
   - 每个器件先转到要求的引脚朝向，再把锚定引脚平移到规划坐标；
   - 逐条画导线并命名网络，放地标识；
   - 把不用的排母引脚标为非连接；
   - 加功能块框和说明文字。
3. PCB：
   - 从原理图导入；
   - 画板框和 4 个 Φ3.2 安装孔；
   - 按焊盘朝向和锚点摆放器件；
   - 按逐网规划的坐标，用 `pcb_PrimitiveLine.create` 逐段落线，加 GND 过孔（删 D1 后为 6 个）；
   - 建顶、底两面 GND 覆铜。

   没有调用自动布线或自动布局。
4. 关闭会话后用文本方式修改 TP 封装孔径（见下文）。随后从磁盘重开，重铺覆铜，运行规则检查，导出网表和 Gerber 并核对。
5. 脚本放在仓库外的临时目录，没有入库。

## 测试钩封装孔径

- 2026-11-05 改用鳄鱼夹供电后，TP4（5010）、TP5（5011）两只多用途测试钩的库封装孔径分别是 2.0 mm 和 1.87 mm；DigiKey 给这两款的安装孔都是 0.063 in（1.60 mm）。用同样的方法把两个文件里的孔径都改为 62.992 mil（1.60 mm），重开后读回正确。
- 系统库 `TEST-TH_BD2.54-P1.39`（Keystone 5000 系列）的孔径是 1.39 mm。DigiKey 等分销商给 5001 的安装孔是 0.040 in（1.02 mm）；这种测试钩是卡扣式安装，孔太大会卡不住。
- 关闭会话后，把原理图和 PCB 文件里两份嵌入封装的孔径都由 54.724 mil 改为 40.157 mil（1.02 mm），改前文件备份在仓库外。
- 重开后读回，TP1–TP3 的孔径都是 1.02 mm；Gerber 钻孔文件里有 3 个 Φ1.02 孔和 2 个 Φ1.60 孔。
- 没有拿到 Keystone 的原始图纸。
