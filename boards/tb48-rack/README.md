## 功能与边界

2026-11-05 已定：

- 两片刀片焊在 PCB 的金属化长槽里，顶、底两层覆铜直接连到 XT60，没有走线。
- **不设开关**：通断靠 TB48 自带的开机键（短按一次再长按）。电池开机后 XT60 一直带电，最好关机后再插拔。
- **不设保险丝、TVS 和电解电容。**
- 不接电池的信号触点，不读电池信息。
- 不放指示灯：板子装在导向框里看不见，原来的待定项取消。
- 只用于调试，不用于比赛和检录。

待定：

- 导向框与固定方式。
- 刀片的实际厚度，以用户手上那个转接件的刀片实测为准。
- 设计电流。

## 接口

PCB 坐标（mm）与[官方电池架模型](docs/mechanical-reference.md)的换算：**x = X − 79，y = −Z**，原点在电池腔壁线与腔中线的交点；从电池一侧往下看，+x 朝右、+y 朝上。

| 位号 | 信号 | 位置与要求 |
| --- | --- | --- |
| J1 | BAT− 刀片 | 槽中心 (3.695, 0.6)，长轴沿 y。靠近电池信号触点的一片 |
| J2 | BAT+ 刀片 | 槽中心 (3.695, −10.4)。离信号触点远的一片，极性由用户于 2026-11-05 确认 |
| J3 | XT60PW-F 母座 | 装在底面，插口朝 +x。3 脚（+）在 (8.8, −8.5)，4 脚（−）在 (8.8, −1.3)；1、2 脚是固定脚，不接网络 |
| H1、H2 | 安装孔 | M2，(20.5, 5.0)、(20.5, −14.8) |

刀片仿照官方模型：宽 7.1 mm、厚 1.27 mm、中心距 11.0 mm，尖端朝上插进电池顶盖底面。伸出落座面的高度：正极 2.45 mm，负极 3.95 mm（负极先接触、后断开）。

## 刀片选型与装配

- **材料**：H62 黄铜板或黄铜条，厚 1.2 mm；能买到 1.3 mm 的更接近官方的 1.27 mm。先量一下转接件的刀片再定。
  - 宽 7.0–7.1 mm：可以买 8 mm 宽的锉到 7.1 mm，或用 1.2 mm 黄铜板裁条。
  - 黄铜比紫铜硬，插拔不容易变形。按截面 7.1 × 1.2 mm、长约 10 mm 计算，电阻约 0.08 mΩ（H62 电阻率按 6.4 × 10⁻⁸ Ω·m），15 A 时发热约 0.02 W（计算）。
  - 镀锡可选。
- **尖端**：两侧各锉出 0.4 mm、长 0.8 mm 的倒角，和官方刀片一样。
- **长度**：刀片长度 = 伸出落座面高度 + 导向框顶板厚 + 顶板到 PCB 的间隙 + 1.6 mm（板厚），底端与 PCB 底面齐平。
  - 暂按顶板 2.0 mm、间隙 2.0 mm（给 XT60 焊点留空间）计算：BAT− 9.55 mm，BAT+ 8.05 mm。
  - 导向框定了以后按实际尺寸重算。
- **焊接**：先把 PCB 底面贴在一块平板上，刀片竖直插到底，再从顶面焊。两面 2 oz 铜皮直连，吸热大，要用 60 W 以上的烙铁加大刀头，或者先预热。
- 槽宽 1.45 mm，厚 1.2–1.3 mm 的刀片都能放进去。刀片在 x 方向的位置由槽决定，余量约 ±0.1 mm。

## 打开与编辑

- 用上述客户端打开工程入口，保留整个 `hardware/` 目录：工程索引、`sch/电池架原理图/`（单页 `01_电池架原理图`）和 `pcb/电池架PCB.epcb2`。工程内的板子名为“TB48电池架”。
- 器件都来自客户端系统库：J3 用 XT60PW-F（C428722）；J1、J2 借用 RH-5128（C7589097）的符号和封装，不进 BOM。
- 嵌入封装改动。原理图和 PCB 两份都改了，**不要对 J1、J2、J3 执行“从库更新封装”**：
  - J1、J2（`TH_BD3.2-D2.0`，封装名未改）：
    - 焊盘改为 7.4 × 1.45 mm 金属化长槽、9.2 × 3.4 mm 椭圆焊盘；
    - 丝印改为焊盘外框，器件外形层改为刀片截面 7.1 × 1.27 mm；
    - 3D 模型仍是 RH-5128 的原模型，不代表刀片。
  - J3（`TH_2P-XT60PW-F`），按 AMASS XT60PW-F30 规格书（2023V2）修正，原库封装的孔偏小：
    - 电源针孔 Φ2.8 → Φ3.0 mm，焊盘 Φ3.8 → Φ4.2 mm（规格书 Φ2.90 +0.10/0）；
    - 固定脚槽 0.6 × 1.5 → 0.9 × 2.0 mm，焊盘 2.2 × 1.3 → 2.6 × 1.5 mm（规格书 0.80 × 1.90，+0.10/0）。
- PCB 规则在客户端自带的“JLCPCB Capability(Two Layers Board)”基础上改了两处：
  - 覆铜对焊盘改为直连：默认热焊的辐条只有 0.254 mm，过不了 15 A；
  - 安全间距与线宽改用 `copperThickness2oz` 表，与下单的 2 oz 一致。
- 原理图和 PCB 都用客户端命令行的无界面会话、通过编辑器 API 绘制；嵌入封装用文本方式修改。没有使用自动布线或自动布局，功率路径只有覆铜。
- 客户端 4.1.71 这次遇到的坑：
  - `dmt_Project.createProject` 的文件格式参数要写小写的 `eprj3`，写 `EPRJ3` 会按默认格式建成 `.eprj2`。
  - 用命令行打开新工程时，会自动生成一套 Board1、Schematic1、PCB1、Panel1，要删掉。
  - PCB 数据坐标是 +y 朝上、单位 mil；原理图画布的 Y 是数据 Y 取负。
  - 底面器件的转角要按回读的焊盘坐标确认：J3 转 270° 时插口朝 −x，正负极也会反过来，实际用 90°。
  - API 新建的覆铜要保存、重开后才能用 `rebuildCopperRegion` 填充（缓启动板也是这样）。
  - 用 `sch_PrimitivePin.modify` 把引脚标为不连接时，引脚 Y 坐标会被取反，要随后把原坐标写回（缓启动板也是这样）。
  - 原理图里挪了器件、重画了导线，要在 PCB 里“从原理图导入变更”，否则重开后 DRC 报 Netlist Error。
  - 原理图画布截图在 `zoomTo` 之后有时是空白；预览图改用 `sch_ManufactureData.getSvgFile` 导出后裁剪。
  - 同一台机器上另一块板的会话重启过命令行服务，本板的会话随之丢失。每次修改前先确认会话还在，改完回读磁盘文件。

已知问题与限制：

- **没有过流保护**：TB48 放电时只有 ≥ 200 A（延时约 200 µs）的短路保护；放电过温只置标志位，不关断（来源同上，RMU 2024 圆桌）。所以 22.5–200 A 的过载电池不会断开。本架又不设保险丝，刀片接触不良或负载异常时可能持续发热，使用时要有人看管。
- **XT60 的正负极只来自立创库符号**（3 脚为 +），AMASS 规格书没有标极性。
  - 焊之前对照 XT60 外壳核对：通常平角一侧是 +、斜角一侧是 −，这是经销商资料，没有原厂出处。
  - 焊好后先插上 TB48 量 XT60 输出，再接车。
- **电池端子极性只有用户确认，没有资料佐证**。2026-11-05 查过以下资料，都没有标注 TB48 端子哪片是正极：DJI 悟 1 / M100 / M600 资料、RoboMaster 电池架 V1 与电池架 2 说明书、官方电池架 STEP、立创开源平台和 GitHub。
- 刀片几何照抄官方电池架模型，TB48 插槽本身的尺寸没有资料。官方模型没有材料、镀层和插拔力，模型是 2017 年的设计数据，和实物是否一致待确认；“顶盖落在 Y 0 面上”“刀片插进顶盖底面插槽”是按几何关系推断的。
- PCB 顶面在落座面以下 4.0 mm（顶板 2.0 mm + 间隙 2.0 mm）是假设，它决定了刀片长度。导向框还没有设计。
- 定位与固定：刀片一端靠刀片穿过导向框顶板来定位，XT60 一端靠两个 M2 螺钉固定。螺钉从底面拧入，孔边离 XT60 外壳约 2 mm，螺钉头直径要 ≤ 3.8 mm，待确认。
- 顶面丝印（BAT−、BAT+、板名）会被导向框盖住，底面另印了一份 BAT−、BAT+。
- 2026-11-05 第一版机械参考把刀片的焊脚误当成接触区，同日已更正，见[机械参考](docs/mechanical-reference.md)开头的说明。
- 用户另有一个两片刀片转 XT60 的转接件，两片刀片看起来是对称的。如果它能翻转 180° 插进电池，输出极性就会反过来，要在转接件和电池上做好标记。

## 下一步

1. 量转接件刀片的宽度和厚度，和官方模型的 7.1 × 1.27 mm 对照，决定买 1.2 mm 还是 1.3 mm 的黄铜。再对照一块 TB48 实物，确认插槽中心距 11.0 mm。
2. 设计导向框：电池腔 76.0 × 41.0 mm，顶盖落座区 97.5 × 49.4 mm，顶板上开两条刀片槽。PCB 顶面放在落座面以下 4.0 mm；框的尺寸变了就重算刀片长度。
3. 框定下来后核对 PCB 外形和 M2 孔位，必要时调整；然后按仓库规定提交，从该提交导出生产文件投板（两层、1.6 mm、外层 2 oz）。
4. 样板验证：
   - 先不接车，插上 TB48 量 XT60 的极性和电压；
   - 再接 10–15 A 负载，测刀片、焊点和 XT60 的温升与压降。
