## 3. 硬件拓扑

功率板是四开关同步 Buck-Boost。输入侧接 24V 电池/裁判系统母线，输出侧直通底盘母线，超级电容通过双向 FSBB 接入母线作为能量缓冲。

主要器件：

| 模块 | 当前状态 |
|---|---|
| MCU | STM32G474CET6 |
| 主功率 MOS | CSD18540Q5B，60V，四颗 |
| 功率电感 | SER2918H-103KL，约 10uH |
| 半桥驱动 | SLM27211CB-DG |
| 输入/输出分流 | 3mΩ |
| 电容支路分流 | 1.5mΩ，2 颗 3mΩ 并联 |
| 输入/电容 TVS | SMCJ28A |
| 电流采样 | INA240A1 + STM32 内部 OPAMP + ADC |
| 电压采样 | OPA2350 差分/分压链路 + ADC |
| 通信 | FDCAN2，经典帧，1Mbps |

注意：当前实物电容支路采样电阻按 1.5mΩ 校准；现有 `功率控制板下板.tel` 可能仍只反映原始单颗 3mΩ 网表，未体现后续并联改线。控制代码和本文档以当前实物为准。

- `C_IN+/-`：输入侧功率/采样网络。

## 5. 核心控制逻辑

当前主控制链路：

```text
ADC 采样
  ↓
一阶低通滤波
  ↓
计算 in/out/cap 的 U/I/P
  ↓
直接读取 out.P_now 作为底盘侧功率
  ↓
功率平衡基础项 + Pin 外环 PI，计算目标电容功率
  ↓
除以 cap.U_now 得到目标电容电流 charge_curr
  ↓
低压禁放、充放电限幅、目标电流限速
  ↓
cap.U_now / in.U_now 前馈
  ↓
Vcap/Vin 占空比前馈 + 位置式电容电流 PID
  ↓
与基于原始电容电压的 32V P型 CV 变比上限竞争，取较小值
  ↓
占空比限速
  ↓
FSBB PWM 更新
```

功率目标公式：

```c
pin_target_power = buckboost.max_power_lim - INPUT_POWER_MARGIN_W;
pin_error = pin_target_power - in.P_now;
target_cap_power = (pin_target_power - out.P_now)
                 + INPUT_POWER_LOOP_KP * pin_error
                 + input_power_iout;
charge_curr = target_cap_power / cap.U_now;
```

`pin_target_power-out.P_now` 是功率平衡基础项，不是占空比前馈。输入功率 PI 只修正目标电容功率，除以电容电压后得到目标电容电流；它不会直接修改占空比。当前不使用D项，外环保持`Kp=0.45`、`Ki=0.00005`。

外环积分采用条件积分抗饱和：充电命令已经触及正向上限且`Pin`仍低于目标时，冻结本周期积分更新；放电命令已经触及负向下限且`Pin`仍高于目标时同样冻结。若误差方向有助于退出限幅，则允许积分继续变化。原先把全部限流功率差在一个控制周期内硬回算进积分的做法已移除，避免回收临时5A限流或27.5～28V软限流留下持续数秒的负积分记忆。

## 6. 急刹回收逻辑

回收模式由 `update_regen_state(out.I_now)` 判断。

当前阈值：

| 参数 | 当前值 | 说明 |
|---|---:|---|
| `REGEN_OUTPUT_CURRENT_THRESHOLD_A` | -0.1A | 输出电流明显为负时进入回收候选 |
| `REGEN_OUTPUT_CURRENT_RELEASE_A` | -0.03A | 回收退出迟滞 |
| `REGEN_ENTER_DEBOUNCE_CYCLES` | 20 周期 | 20kHz 下约 1.0ms（更快回收测试档） |
| `REGEN_EXIT_DEBOUNCE_CYCLES` | 30 周期 | 20kHz 下约 1.5ms |

普通充电上限为 5A。检测到急刹回收后，瞬时电容充电电流上限提升到 10A，目标电流限速切到回收档。10A 是针对当前 24V、77W 典型工况的保守降额；它限制的是电容侧电流，不等价于任意工况下输出负向电流都绝对小于 10A。

这些阈值和防抖值均为未经实物验证的当前假设值，必须上板观察母线电压、电感电流、MOS 温升和振铃后再定版。

### 7.1 快速调参入口

目标电容电压、输入欠压关断等常用阈值集中在 `USER/Inc/power_calculation.h`，无需在控制源文件中分散查找：

| 参数 | 当前值 | 语义与联动 |
|---|---:|---|
| `CAPV_MAX` | 28V | 正常目标电容电压/充电上限。正向充电电流从 `CAPV_MAX-CAPV_CHARGE_DERATE_WINDOW` 开始线性收紧，当前即 27.5～28V；修改它会同步平移该软降额窗口，但不会自动修改 `CV_HIGH_TARGET_V`。 |
| `INV_MIN` | 19V | 输入欠压阈值；`in.U_now <= INV_MIN` 时本周期强制关 PWM，持续欠压还会触发输入掉电锁存。 |
| `INV_RECOVERY_HYSTERESIS_V` | 4V | 输入掉电锁存的恢复迟滞。输入需持续恢复到高于 `INV_MIN + INV_RECOVERY_HYSTERESIS_V`，当前即高于 23V，才允许解锁；它不是独立的关断阈值。 |
| `CAPV_MIN` | 7V | 电容最低禁放阈值。放电电流从 `CAPV_DERATE_START` 向下逐步降额，并在到达 `CAPV_MIN` 时收紧为 0；修改后需同时检查二者之间的降额区间。 |
| `CV_HIGH_TARGET_V` | 32V | 使用校准后原始电容电压的 P-only 直接 PWM 变比上限，主要兜底未接外部电容等空载异常升压；它不是正常充电目标，应保持在 `CAPV_MAX` 之上并留出经过实测确认的安全层级。 |

修改这些参数后必须重新编译，并从低功率、限流条件开始验证。尤其是 `CAPV_MAX` 与 `CV_HIGH_TARGET_V`、`INV_MIN` 与恢复迟滞应成对检查，避免正常控制目标和保护层级发生倒置或频繁抖动。

注意：`INV_MIN` 的判断虽然每个 20kHz 控制周期都会执行，但 `in.U_now` 来自当前 50Hz 低通后的输入电压；实际欠压响应还包含该滤波延迟。`FF_MIN_BUS_VOLT` 目前直接别名到 `INV_MIN`，修改欠压门槛也会同步改变电压比前馈的最低有效输入电压。

## 8. PID 和前馈

控制分为两层：外层输入功率PI只生成目标电容电流；内层占空比控制才使用电压比前馈和位置式电流PID：

```c
feedforward_ratio = cap.U_now / in.U_now;
cloop = feedforward_ratio + PID_calc(&curr_loop, cap.I_now, smoothed_charge_curr);
vloop_high = feedforward_ratio + PID_calc(&volt_high_loop, capv_raw, 32.0f);
ratio_pass = min(cloop, vloop_high);
```

含义：

- 占空比前馈 `cap.U_now / in.U_now` 给出接近零电流平衡点的变换比。
- 电流 PID 只负责修正电容电流误差。
- 27.5～28V 只线性收紧正向充电电流目标；达到 28V 后正向充电上限为 0，负向放电仍允许。
- 32V 高压 CV 使用校准后的原始 `cap_v`，不经过50Hz低通；它是P-only单向变比上限，不存在低压区积分蓄积。
- 正常接入超级电容时由电流环控制；只有电流环要求的变比高于32V CV允许值时，CV才直接压低PWM。
- CV占优或占空比限速时，电流PI反跟踪实际应用的变比，避免CV退出后的隐藏积分跳变。

PWM 落地映射按前后半桥分开计算，理想关系为：

```text
Vcap / Vin = D_TA_top / D_TB_top
```

当 `volt_ratio <= 1` 时，`D_TA_top = volt_ratio * MAX_PWM_RATIO`，`D_TB_top = MAX_PWM_RATIO`。
当 `volt_ratio > 1` 时，`D_TA_top = MAX_PWM_RATIO`，`D_TB_top = MAX_PWM_RATIO / volt_ratio`。
这样 `MAX_PWM_RATIO=0.97` 只作为每个半桥各自的自举余量，不再在 `ratio≈1` 附近形成假 1:1 平台。
最终每个半桥占空比还会独立夹在 `MIN_PWM_RATIO=0.03` 到 `MAX_PWM_RATIO=0.97`，低于/高于物理可实现范围的极端变比会被硬件边界截断。

## 9. 限幅和保护边界

当前保留的核心边界：

- `in.U_now <= INV_MIN` 时强制关 PWM。
- 电容电压低于 `CAPV_MIN=7V` 且目标为放电时，强制目标电容电流为 0。
- 目标电容电流限幅：普通充电 5A，回收瞬时 10A，15V 以上最大放电 -14.5A。
- 电容电压在 27.5～28V 时，所有正向充电上限线性收紧；达到 28V 后禁止继续充电，但不拦截放电。
- 校准后的原始电容电压参与32V P型CV变比竞争，空载板载电容快速升压时直接限制PWM；该通道不使用50Hz慢滤波。
- 电容电压从 15V 降到 7V 期间，最大放电电流按三次曲线逐步收缩到 0A；前段收得慢，接近 7V 时快速收紧，减少低压大电流导致的端电压塌陷和锯齿。
- 占空比最终夹在 `0..max_volt_ratio`。
- `ratio<=0` 时通过 `force_power_stage_off()` 关闭四路 HRTIM 功率输出，而不是只写 0% 占空比。
- `hard_power_loss_latch` 输入掉电锁存已恢复：输入功率近零且输出侧仍有功率，或输入电压低于 `INV_MIN` 持续防抖后，锁存关 PWM；输入电压稳定高于 `INV_MIN + INV_RECOVERY_HYSTERESIS_V` 一段时间后自动解锁，当前恢复门槛为 23V。该策略为原有保护，仍需实物调试。
- 看门狗 IWDG 保留，控制环停摆时复位 MCU。

已移除的策略性软件保护：

- 输入母线过压分段限流/硬关断。
- 独立的回收专用分段降额；当前只保留所有充电共用的 27.5～28V 单向软降额。
- 额外状态 flag 上报。
- 额外电容过压锁存保护。

电容高压侧采用分层控制：27.5～28V单向充电电流软降额为正常主限制，32V P型CV只作为更高一级的直接PWM变比上限。

## 10. CAN 协议

接收：

- 使用 1Mbps 经典 CAN 标准帧。`ROBOT_TYPE=1` 时接收 ID 为 `0x200`（步兵/哨兵），`ROBOT_TYPE=2` 时为 `0x2FF`（英雄）。
- 功率上限来自底盘主控有效载荷的 `[4:5]`，按高字节在前解析为无符号 16 位值；接收回调要求标准数据帧、ID 匹配且 DLC 至少为 6 字节，短帧不会被读取或采用。
- 未收到 CAN 覆盖前，默认 `can_target_power_lim = 100W`，用于当前台架充电测试。
- 低于 40W 的原始值按 40W 处理。
- 正常情况下 `can_target_power_lim = raw - 1W`，再由功率目标公式内部保留额外 2W，总体约 3W 裕量。

发送使用经典 CAN 标准帧 ID `0x211`、DLC 8；四个字段均按小端编码：

| 字节 | 内容 |
|---|---|
| `[0:1]` | 带符号输入功率 `in.P_now`，`int16_t`，单位 W |
| `[2:3]` | 带符号输出功率 `out.P_now`，`int16_t`，单位 W |
| `[4:5]` | 电容电压 `cap.U_now × 100`，`int16_t`，单位 0.01V |
| `[6:7]` | 带符号电容实际功率 `cap.P_now`，`int16_t`，单位 W；正值为充电、负值为放电 |

CAN 故障恢复已拆分为轻量中断侧检测和主循环恢复：TIM4 的 1ms ISR 只调用 `CAN_WatchdogCheck()` 检查超时并置 `can_health.needs_reinit`，不会在中断中停止或重配外设；主循环持续调用 `CAN_Service()`，在需要时依次屏蔽 FDCAN IRQ、执行 RCC 外设强制复位、重新调用 `HAL_FDCAN_Init()`、配置过滤器并启动通知，全部成功后才重新开放 IRQ。Bus-Off、外设错误、连续发送失败、启动初始化失败或已激活总线的接收超时均可提出恢复请求。完整重初始化任一步失败时请求标志保持，`CAN_Service()` 以至少 10ms 的尝试间隔继续重试；成功后才清除请求并恢复通信。

## 11. GCC/CMake 构建

推荐使用仅依赖 Python 标准库的工程脚本。以下示例以工程根目录为当前目录；从其他目录运行时，只需把脚本路径写成相对该目录或绝对路径，脚本会始终根据自身位置解析工程根目录和构建目录，不依赖当前工作目录。

```powershell
# 配置并编译主固件
python tools/一键编译.py

# 默认先重新编译，再以 4000kHz SWD 写入、校验并复位
python tools/一键烧录.py

# 可选修改 SWD 频率
python tools/一键烧录.py --freq 4000
```

```text
链接器内存区域统计：
FLASH: 52404 B / 512 KiB, 9.99%

arm-none-eabi-size 的 ELF 段字段：
text: 51912 B
```

两组数字口径不同：前一组是链接器按 FLASH/RAM memory region 给出的实际区域占用，后一组是 `arm-none-eabi-size` 对 ELF 的 `text/data/bss` 字段统计；其中装载地址、运行地址、对齐和填充的归属不同，不能把两组数字直接混为同一个“固件大小”。

## 12. 当前需要实物调试的项目

必须上板验证：

- 20kHz 控制频率下 TIM1 ISR 余量。
- `INPUT_POWER_LOOP_KP=0.45`、`KI=0.00005`对急加速首峰、跟随速度、回摆和稳态纹波的影响。
- 条件积分在回收5A→10A切换、27.5～28V充电软限流、7V禁放和-14.5A放电饱和时，是否只冻结推向限幅方向的积分，并允许积分向退出限幅方向恢复。
- `CURR_STEP_DISCHARGE=0.75` 对急加速响应和电感峰值的影响（20kHz 下约 15kA/s，0→14.5A 约 0.97ms）。
- `CURR_STEP_CHARGE=0.50` 对普通充电平滑性和输入母线扰动的影响。
- `CURR_STEP_REGEN=0.60` 对急刹回收吸收能力和母线振铃的影响（20kHz 下约 12kA/s，0→10A 约 0.83ms）。
- `DUTY_RATIO_STEP=0.018` 对电感电流单步过冲、MOS 温升和栅极振铃的影响。
- 10A 回收充电上限在不同 `Pin/Vcap/Vin` 工况下是否仍覆盖输出电流采样负向量程，并检查电容、分流、MOS 和连接器温升。
- 27.5～28V 单向充电软降额是否足够平滑，达到 28V 时是否仍有明显正向充电电流。
- 未接外部超级电容、24V输入限流条件下，32V原始电压CV是否及时接管，并检查CV退出后的电流PI无扰恢复。
- `ESR_COMP_OHM=0.35` 是否符合实物电容组、线束和连接器总等效电阻。

## 13. 注意事项

- 不要直接用旧启动文件或旧 scatter 文件参与 GCC 构建。当前有效文件是 `Core/Startup/startup_stm32g474xx.s` 和 `Core/Linker/STM32G474CETx_FLASH.ld`。
- 不要把 `.build/`、`.elf`、`.hex`、`.bin`、`.map` 提交或放到根目录。
- 删除清理必须使用 Windows 回收站等可恢复方式。
- 修改控制参数后，先低功率限流上板，再逐步提升功率和回收强度。
- 当前固件基础功能此前运行正常，后续改动应优先保持核心功率链路不变，只局部调参数或调 PID。
