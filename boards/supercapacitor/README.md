| --- | --- |
| 原生客户端重开与渲染 | 两页原理图、两块 PCB 均可打开并导出预览 |
| 转换前后网表 | 四份网表分别一致，比较时仅排除路径决定的 `projectId` |

| 文档记录与工程设置 | 原生记录内容一致，仅统一行分隔；设置经客户端回导核对一致 |
| 功率板原理图规则检查 | 转换前后均为 1 条 `ATTRMATCHCODE` 警告，涉及 CN8 / CN9 |
| 控制板原理图规则检查 | 转换前后均为 5 条警告：`GLOBALNETSHORTED` ×1、`FLAGTONET` ×2、`ONENETNAME` ×1、`ATTRMATCHCODE` ×1 |

| 实物、制造与装配 | 本次未验证；已有投板与实测记录待补充 |
