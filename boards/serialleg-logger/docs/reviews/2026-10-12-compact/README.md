# R0.3 紧凑版布局与制造检查

日期：2026-10-12。嘉立创专业版 4.1.71.7a7261be，使用原生 CLI/API；未使用 computer use、自动布线器或自动寻路。基线提交 `27a9aebb6f87ded35f4d1f7330f6f76075f9c465` 加工作区 R0.2 修改。正式工程 PCB 版本 `1791780408455`，原理图版本 `1791733447480`，见 [快照](snapshot.json)。当前仍为草稿，未投板、未实测、无生产标签。

## 修改结果

板框由 55 × 47.54 mm 缩至 **40.64 × 47.54 mm**，宽度减少 14.36 mm。外接矩形面积减少 26.1%；扣除缺口后的板框面积由 2124.39 降至 1666.03 mm²，减少 21.6%。这两个比例口径不同，不把外接矩形缩减量当成实际板材面积缩减量。

调整了 23 个器件的坐标、旋转或面层：USB 插座与 ESD/输出电容集中在下沿，检测与联锁外围放到底面，三只按键集中在上沿。修正了电容与 USB 插座、电阻与限流芯片、电容与串阻之间的本体间距；更新受影响的电源、USB、控制线、接地过孔与丝印。J1 直插接口、安装孔、P6/P11 避让、USB/UART、microSD 和三只按键均保留，器件型号和电气网表未改。

当前 626 条 LINE、129 个 VIA，原生保存会合并或拆分部分共线段，数量变化不是布线质量指标。受影响网络均人工逐网指定路径后由原生 API 落图；保留部分导入前历史走线，不能称为从零全手工布线。[布局变化](layout-changes.json)记录移动器件；[重复图元检查](primitive-check.json)确认无重叠写入的相同线段或过孔。

独立检查使用本轮原生 Gerber、Python 与 Shapely 2.1.2，脚本 [check_manufacturing.py](../../../tools/check_manufacturing.py) 和规则阈值沿用 R0.2。未通过放宽规则获取通过结果。

| 丝印到阻焊开窗 | ≥0.15 mm | 顶面最小约 0.262 mm，底面约 0.838 mm |

完整结果见 [manufacturing-check.json](manufacturing-check.json)，输入快照见 [native-geometry.json](native-geometry.json)。这是指定几何筛查，**不是原生完整 DFM 或板厂 CAM 认证**。圆弧采用折线近似，阻焊桥仅比较独立开窗；钢网厚度、开口面积比、全部器件高度和生产公差未覆盖。Gerber/PDF 临时导出位于板内 `outputs/compact-2026-10-11/`，未作为生产包发布。

本体检查使用内嵌封装 layer 48 外形与原生焊盘坐标拟合安装变换，0.20 mm 仅为筛查阈值。新布置 C10/J2 的名义本体间隙约 0.303 mm，C15/R9 约 0.440 mm。原有 U4/C12 和 U2/C2 分别约 0.182 / 0.130 mm，位置与面层未改、没有本体重叠，但装配及返修空间仍需工艺复核。原生装配图外框可能含庭院边界，不能直接当成精确实体外壳。
